# 自動入力・フォーム保存・スクリーンショット

いずれの機能も、先に認証済みセッションに入っている必要があります（→ [usage_getting-started.md](usage_getting-started.md)）。未認証の状態でこれらの操作をすると、認証を求める Popup が先に開きます。

## 自動入力

1. 入力フィールドがあるページを開く
2. 入力フィールドで右クリックし、コンテキストメニューから「情報を入力...」を選ぶ（キーボードショートカット `Ctrl+Shift+F` でも開始できる）
3. 候補の一覧から保存済み情報を選ぶ
4. 入力する項目を選ぶ
   - **すべて入力**: ユーザー名、パスワード、追加フィールドをまとめて入力
   - **個別入力**: 特定のフィールドだけを選んで入力
5. 候補画面では「✏️ フィールドを編集...」から追加フィールドをその場で編集できる

登録されていない URL で自動入力を行うと、その URL を追加するか確認が出ます。承認すると、正規化された URL が自動で追加されます。

## フォームの保存

- フォーム上で右クリックし「現在のフォームを保存」を選ぶと、フォームの全フィールドを自動検出して保存できる
- 検出された項目のうち、ユーザー名・パスワード以外は追加フィールドとして保存される

## お気に入り

よく使う入力を、ドメインごとに最大3つ（スロット 1〜3）まで登録し、ショートカット等で即座に実行できます。

- 自動入力の候補画面に表示されるお気に入りバーで、スロットをクリックすると登録モードに入り、その状態でフィールドを選ぶと、その入力内容がお気に入りとして保存される
- 登録済みスロットの削除ボタン（×）から削除できる（バー内に確認が出る）
- 実行すると、登録時に記録したフィールド対応（セレクタと入力元の対応）に基づいて入力される

## スクリーンショット

- `Ctrl+Shift+S` で現在のタブを撮影する
- 撮影後の動作（クリップボードにコピー / 画像をダウンロード）は設定の Screenshot タブで切り替える（→ [usage_options.md](usage_options.md)）。ダウンロード時のファイル名は `screenshot_<日時>.png` 形式

## キーボードショートカット

既定の割り当ては以下のとおりです。変更は `chrome://extensions/shortcuts`、または設定の Others タブのボタンから行います。

| ショートカット | 動作 |
|---|---|
| `Ctrl+Shift+S` | スクリーンショットを撮影 |
| `Ctrl+Shift+F` | フォームに情報を入力（自動入力） |
| `Ctrl+Shift+1` | お気に入り 1 を実行 |
| `Ctrl+Shift+2` | お気に入り 2 を実行 |
| （割り当てなし） | お気に入り 3 を実行。Chrome の仕様で既定ショートカットは最大4つのため、`chrome://extensions/shortcuts` で手動で設定する |

## 未撮影の画面

| 画面 | 理由 |
|---|---|
| 右クリックのコンテキストメニュー、自動入力の候補選択 / フィールド選択ダイアログ、お気に入りバー | 認証済みセッションが前提の画面であり、Windows Hello 認証を完了できない撮影環境（Linux 上の Chromium）では表示できない |
| スクリーンショット撮影の結果（ダウンロード / クリップボード） | 撮影操作自体は拡張のショートカット経由でのみ発火し、上記と同じく認証・運用中の Windows 実機環境が必要なため、本撮影では再現していない |
