# ドキュメント構成

このプロジェクトのドキュメント構成と更新方針を記載します。

## 常時更新が必要なドキュメント

なし

## リリース時更新が必要なドキュメント

なし

## ドキュメント更新のタイミング

- 以下の場合はドキュメント更新を検討
  - 新機能の追加
  - ユーザー向け設定の変更
  - 仕様の重要な変更

