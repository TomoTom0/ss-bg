# ドキュメント構成

このプロジェクトのドキュメント構成と更新方針を記載します。

## 常時更新が必要なドキュメント

なし

## リリース時更新が必要なドキュメント

なし

## ドキュメント更新のタイミング

- 以下の場合はドキュメント更新を検討
  - 新機能の追加
  - ユーザー向け設定の変更
  - 仕様の重要な変更

## 現在のドキュメント構成

```
docs/
├── design/          # 設計関連のドキュメント
│   ├── decision/    # 技術的決定事項（ADR）
│   ├── detailed/     # 詳細設計
│   └── initial/      # 初期設計
├── research/        # 技術調査レポート
└── chrome-store/    # Chrome Web Store掲載用ドキュメント
    ├── README.md           # ストア掲載用テキスト
    ├── store-listing.md    # 掲載情報・権限説明・プライバシー実践宣言
    └── privacy-policy.md   # プライバシーポリシー
```
