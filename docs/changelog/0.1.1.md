# 0.1.1

## 新機能

- お気に入りの削除 UI を追加
  - パスワード選択ダイアログのお気に入りバーで、登録済みスロットに削除ボタン（×）を追加。従来は別のお気に入りで上書きする以外に消す方法がなかった
  - 削除時はバー内に確認（削除／キャンセル）を表示してから `DELETE_FAVORITE` を送信し、バーを再描画する
  - content.test.ts: お気に入りバーのテスト追加（削除ボタンの表示、キャンセル時の不送信、削除確定時の送信と再描画）

## バグ修正

- パスワード更新が新規レコード追加になる不具合の修正
  - options/App.vue: 編集時は `UPDATE_PASSWORD`、新規時は `SAVE_PASSWORD` に分岐
  - content.ts (showFieldEditorDialog): `SAVE_PASSWORD` → `UPDATE_PASSWORD` に修正
  - content.ts (suggestAddingCurrentUrl): `SAVE_PASSWORD` → `UPDATE_PASSWORD` に修正
  - background.test.ts: `UPDATE_PASSWORD` ハンドラのテスト追加
  - options/App.test.ts: 編集保存時に `UPDATE_PASSWORD` が送信されるテスト追加
  - background.test.ts: crypto.subtle.exportKey/importKey モック追加でUnhandled Rejection問題解消

- ダークテーマで白背景に白文字になる不具合の修正
  - 注入ダイアログ要素に明示的な `color: #333` を追加（10要素）
  - content.test.ts: ダイアログCSSのcolor検証テスト追加
  - content.ts: テスト用エクスポート関数追加

- キーボードショートカットが動作しない問題を修正: manifest の commands に既定ショートカット（suggested_key）が未定義で、全コマンドが未割り当てだった。`Ctrl+Shift+S`（スクリーンショット、README 記載の従来案内どおり）、`Ctrl+Shift+F`（自動入力）、`Ctrl+Shift+1` / `Ctrl+Shift+2`（お気に入り 1 / 2）を既定として追加。Chrome の仕様で既定ショートカットは最大4つのため、お気に入り 3 は `chrome://extensions/shortcuts` での手動設定とする

## 内部改善

- テストスイートが正常終了しない問題の修正
  - content.test.ts: `done` コールバック形式のテスト（動的フォーム対応）を async/await 形式に移行。Vitest 4 では `done` コールバックが非推奨で Unhandled Error となり、全テスト合格でも終了コードが 1 になっていた
