### 説明

#### 短い説明（132文字以内）
```
スクリーンショット撮影と、ローカルで暗号化されたテキスト情報の管理
```

#### 詳細説明
```
bg-ssは、Windowsユーザー向けの生産性向上ツールです。

【主な機能】

■ スクリーンショット
・キーボードショートカット（Ctrl+Shift+S）で素早く撮影
・クリップボードへのコピー、またはファイルとしてダウンロード
・撮影対象のタブを自動認識

■ テキスト情報の管理
・Windows Hello（生体認証・PIN）で保護されたローカルストレージ
・AES-256-GCM暗号化により、データはデバイス内で安全に保護
・WebAuthn PRF拡張を使用したセキュアな鍵導出
・Webフォームの入力内容を保存・再利用可能
・右クリックメニューから素早く入力

【セキュリティ】
・すべてのデータはローカルデバイスにのみ保存されます
・クラウドへのアップロードは行いません
・Windows Helloの認証情報はデバイスに紐づきます
・認証情報が失われると、保存データの復号は不可能です

【必要要件】
・Windows 10 1809以降
・Google Chrome 108以降
・TPM 2.0対応ハードウェア
・Windows Hello（PIN、指紋、顔認証）の設定

【注意事項】
・この拡張機能はWindows専用です
・保存したデータはデバイスに紐づき、他のPCでは使用できません
```
