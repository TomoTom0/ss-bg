### 詳細説明

```
bg-ssは、Windowsユーザー向けの生産性向上ツールです。

【主な機能】

■ スクリーンショット
・キーボードショートカット（Ctrl+Shift+S）で素早く撮影
・クリップボードへのコピー、またはファイルとしてダウンロード
・撮影対象のタブを自動認識

■ テキスト情報の管理
・Windows Hello（生体認証・PIN）で保護されたローカルストレージ
・AES-256-GCM暗号化により、データはデバイス内で安全に保護
・WebAuthn PRF拡張を使用したセキュアな鍵導出
・Webフォームの入力内容を保存・再利用可能
・右クリックメニューから素早く入力

【使い方】

1. 拡張機能のアイコンをクリックして認証（初回のみWindows Helloで登録）
2. Webフォームなどで右クリック →「情報を入力...」を選択
3. 保存済みの情報を選択して自動入力
4. Ctrl+Shift+S でスクリーンショットを撮影

【セキュリティ】
・すべてのデータはローカルデバイスにのみ保存されます
・クラウドへのアップロードは行いません
・Windows Helloの認証情報はデバイスに紐づきます
・認証情報が失われると、保存データの復号は不可能です

【必要要件】
・Windows 10 1809以降
・Google Chrome 108以降
・TPM 2.0対応ハードウェア
・Windows Hello（PIN、指紋、顔認証）の設定

【注意事項】
・この拡張機能はWindows専用です
・保存したデータはデバイスに紐づき、他のPCでは使用できません
```

## プライバシー実践宣言

Chrome Web Storeの「プライバシー実践宣言」フォーム用の回答です。

### ユーザーデータの使用

**この拡張機能はユーザーデータを使用しますか？**
- はい

**どのようなユーザーデータを使用しますか？**
- ユーザーが入力したテキスト情報（ユーザー名、各種フィールド）
- URL情報
- 拡張機能の設定値

**データはどこに保存されますか？**
- ローカルデバイスのみ（Chrome Storage API）

---

### データの共有

**この拡張機能はユーザーデータをサードパーティと共有しますか？**
- いいえ

---

### データのセキュリティ

**ユーザーデータをどのように保護していますか？**
- AES-256-GCM暗号化
- WebAuthn PRF拡張 + HKDF-SHA256 による鍵導出
- Windows Hello（生体認証・PIN）による認証
- すべてのデータはローカルデバイス内にのみ保存

## 権限とその理由

Chrome Web Storeの審査用に、各権限が必要な理由を説明します。

### storage

**目的**: 暗号化されたユーザーデータと設定値の保存

**説明**: ユーザーが保存したテキスト情報をAES-256-GCM暗号化してローカルストレージに保存するために使用します。クラウドへのアップロードは行いません。

---

### activeTab

**目的**: ユーザーがアクティベートしたタブへのアクセス

**説明**:
- ユーザーが拡張機能を明示的に操作（アイコンクリック、右クリックメニュー、キーボードショートカット）したタブにのみアクセスします
- スクリーンショット撮影、フォームへの自動入力、コンテンツスクリプトとの通信に使用します
- ユーザーの許可なしにバックグラウンドでWebサイトにアクセスすることはありません

---

### downloads

**目的**: スクリーンショットのダウンロード

**説明**: 撮影したスクリーンショットをユーザーのローカルフォルダにダウンロードするために使用します。

---

### contextMenus

**目的**: 右クリックメニューの追加

**説明**: Webフォーム上で右クリックした際に「情報を入力...」などのメニュー項目を表示するために使用します。

---

### offscreen

**目的**: オフスクリーン処理（認証等）

**説明**: Windows Hello認証を安全に行うために、オフスクリーンドキュメントを使用します。
