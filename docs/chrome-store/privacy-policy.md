# プライバシーポリシー

**最終更新日**: 2026年2月15日

---

## 1. データの取り扱い

bg-ssは、すべてのデータをローカルデバイス内にのみ保存します。

- クラウドサーバーへのデータアップロードは行いません
- 外部サービスとのデータ共有は行いません
- データの収集・分析・広告配信は行いません

---

## 2. 保存されるデータ

ユーザーが自ら入力した以下の情報が、ローカルストレージに暗号化されて保存されます：

- Webフォームの入力内容（ユーザー名、各種フィールド）
- URL情報
- 拡張機能の設定値

---

## 3. 暗号化について

保存データは以下の方法で保護されています：

- **暗号化方式**: AES-256-GCM
- **鍵の導出**: WebAuthn PRF拡張 + HKDF-SHA256
- **認証**: Windows Hello（生体認証・PIN）

---

## 4. 要求する権限とその目的

| 権限 | 目的 |
|------|------|
| **storage** | 暗号化データの保存 |
| **activeTab** | ユーザーがアクションを起こしたタブへのアクセス（自動入力、スクリーンショット） |
| **downloads** | スクリーンショットのダウンロード |
| **contextMenus** | 右クリックメニューの追加 |
| **offscreen** | オフスクリーン処理（クリップボードコピー等） |
| **scripting** | ユーザーアクション時のコンテンツスクリプト注入（自動入力機能） |

---

## 5. 注意事項

**重要**: 保存されたデータはデバイス固有の認証情報で保護されています。

- データはデバイスに紐づき、他のPCでは使用できません
- Windows Helloの認証情報が失われると、保存データの復号は不可能です
- 重要な情報は別途バックアップを取ることを推奨します
