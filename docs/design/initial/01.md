# 初期要件定義

## プロジェクト概要

特定のPCでブラウザのパスワードマネージャーやパスワード自動入力機能が無効化されている環境において、これを解決するコンパクトなChrome拡張機能を作成する。

## 主要機能

### 1. パスワード管理機能

**背景**
- 特定のPC環境でブラウザのパスワードマネージャーが使用不可
- パスワード自動入力機能が消されている状態での煩雑さを解消

**要件**
- パスワードの保存・管理機能
- フォームへの自動入力機能
- GPG（pass）との連携（可能な限り）

### 2. スクリーンショット機能（補助機能）

**要件**
- カスタマイズ可能なキーボードショートカットで起動
- ブラウザの表示部分（viewport）のスクリーンショット撮影
- 特定のショートカット使用時は撮影直後にトリミング機能を提供

**ショートカット例**
- 基本スクリーンショット: `Ctrl+Shift+S`
- トリミング付きスクリーンショット: `Ctrl+Shift+C`

## 設計方針

- **コンパクト**: シンプルで軽量な実装
- **実用性優先**: 最小限の機能で最大の効果を狙う
- **セキュリティ**: パスワード情報の安全な取り扱い

## 技術スタック

- Chrome Extension Manifest V3
- TypeScript
- Bun（ビルドツール）
