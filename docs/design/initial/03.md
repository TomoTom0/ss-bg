# 詳細仕様の決定

## 決定事項

### 1. パスワード保存のセキュリティ

**方針**: 必ず暗号化する

**実装方法**
- マスターパスワードを使用してAES暗号化
- Web Crypto API（SubtleCrypto）を使用
- マスターパスワードからPBKDF2で暗号化鍵を導出
- 暗号化されたデータをChrome Storage APIに保存

**UX**
- 初回起動時にマスターパスワードを設定
- 拡張使用時にマスターパスワードで認証
- セッション中は復号化されたデータをメモリ保持（オプションでタイムアウト設定）

### 2. パスワード自動入力

**トリガー方法**
- ドロップダウンから明示的に選択した場合のみ自動入力
- キーボードショートカットは使用しない（または後回し）

**UI**
- フォームフィールドにフォーカス時、ドロップダウンを表示
- マッチしたパスワード候補を一覧表示
- ユーザーが選択→自動入力実行

### 3. URLマッチング

**マッチング優先順位**
1. **完全一致**: 登録されたURLと完全に一致
2. **ドメイン一致**: ドメイン部分が一致（サブドメイン含む）
3. **手動選択**: マッチしないパスワードも「他のパスワードを表示」で選択可能

**複数URL登録**
- 1つのパスワードエントリに複数のURLを登録可能
- 例: `https://example.com/login`, `https://example.com/signin`

**データ構造（案）**
```typescript
interface PasswordEntry {
  id: string;
  title: string;           // 表示名
  urls: string[];          // 複数URL対応
  username: string;
  password: string;
  notes?: string;
  createdAt: number;
  updatedAt: number;
}
```

### 4. ポップアップUI

**必要性**: 実装する

**機能**
- パスワード一覧の簡易表示
- クイック検索機能
- 選択したパスワードをクリップボードにコピー
- オプションページへのリンク
- 現在のページに対するマッチング結果表示

**表示内容**
- タイトル
- ユーザー名
- URL（省略表示）
- コピーボタン

### 5. スクリーンショット保存先

**方針**: ダウンロードフォルダに保存（デフォルト）

**将来的な拡張**
- クリップボードにコピーオプション
- 保存先フォルダの指定（File System Access API）

## 技術的な実装詳細

### 暗号化の実装

```typescript
// 鍵導出
const deriveKey = async (masterPassword: string, salt: Uint8Array) => {
  const keyMaterial = await crypto.subtle.importKey(
    'raw',
    new TextEncoder().encode(masterPassword),
    'PBKDF2',
    false,
    ['deriveKey']
  );
  
  return crypto.subtle.deriveKey(
    {
      name: 'PBKDF2',
      salt,
      iterations: 100000,
      hash: 'SHA-256'
    },
    keyMaterial,
    { name: 'AES-GCM', length: 256 },
    false,
    ['encrypt', 'decrypt']
  );
};

// 暗号化
const encrypt = async (data: string, key: CryptoKey) => {
  const iv = crypto.getRandomValues(new Uint8Array(12));
  const encrypted = await crypto.subtle.encrypt(
    { name: 'AES-GCM', iv },
    key,
    new TextEncoder().encode(data)
  );
  return { encrypted, iv };
};
```

### URLマッチングの実装

```typescript
const matchUrl = (currentUrl: string, entryUrls: string[]): number => {
  // 完全一致: priority 2
  if (entryUrls.includes(currentUrl)) return 2;
  
  const currentDomain = new URL(currentUrl).hostname;
  
  // ドメイン一致: priority 1
  for (const url of entryUrls) {
    const entryDomain = new URL(url).hostname;
    if (currentDomain === entryDomain) return 1;
  }
  
  // マッチなし: priority 0
  return 0;
};
```
