# 認証方式の決定: Windows Hello

## 決定事項

**対象OS**: Windows限定
**認証方式**: Windows Hello必須

## Windows Helloについて

### 対応する認証方法

1. **生体認証**
   - 指紋認証
   - 顔認証（Windows Hello対応カメラ）
   - 虹彩認証

2. **PIN**
   - 生体認証デバイスが無い場合のフォールバック
   - 数字のみまたは英数字のPIN

3. **セキュリティキー**
   - FIDO2対応のUSBセキュリティキー

### セキュリティの利点

- **TPMチップ**: ハードウェアレベルで鍵を保護
- **デバイスバインド**: 鍵はデバイスに紐付き、外部流出不可
- **フィッシング対策**: ドメイン認証により偽サイトで動作しない
- **マスターパスワード不要**: ユーザーが覚える必要なし

## 技術的実装

### WebAuthn APIの使用

Chrome拡張からWebAuthn API（Web Authentication API）を使用してWindows Helloにアクセス。

#### 初回登録（鍵ペア生成）

```typescript
const registerCredential = async () => {
  const credential = await navigator.credentials.create({
    publicKey: {
      challenge: crypto.getRandomValues(new Uint8Array(32)),
      rp: {
        name: "SS-BG Password Manager",
        id: "ss-bg.extension" // 拡張機能のID
      },
      user: {
        id: crypto.getRandomValues(new Uint8Array(16)),
        name: "user@ss-bg",
        displayName: "SS-BG User"
      },
      pubKeyCredParams: [
        { type: "public-key", alg: -7 },  // ES256
        { type: "public-key", alg: -257 } // RS256
      ],
      authenticatorSelection: {
        authenticatorAttachment: "platform", // Windows Hello等の内蔵認証器
        userVerification: "required",         // 生体認証・PIN必須
        requireResidentKey: false
      },
      timeout: 60000,
      attestation: "none"
    }
  });
  
  // credentialIdを保存（暗号化鍵の識別に使用）
  return credential;
};
```

#### 認証（復号化時）

```typescript
const authenticateUser = async (credentialId: BufferSource) => {
  const assertion = await navigator.credentials.get({
    publicKey: {
      challenge: crypto.getRandomValues(new Uint8Array(32)),
      rpId: "ss-bg.extension",
      allowCredentials: [{
        type: "public-key",
        id: credentialId
      }],
      userVerification: "required",
      timeout: 60000
    }
  });
  
  // 認証成功時、assertionから鍵を導出
  return assertion;
};
```

### 暗号化鍵の導出

Windows Helloの認証結果から暗号化鍵を導出する方法：

```typescript
// WebAuthnの署名結果からAES鍵を導出
const deriveEncryptionKey = async (assertion: PublicKeyCredential) => {
  const response = assertion.response as AuthenticatorAssertionResponse;
  
  // 署名データをハッシュ化してAES鍵として使用
  const keyMaterial = await crypto.subtle.digest(
    'SHA-256',
    new Uint8Array(response.signature)
  );
  
  return crypto.subtle.importKey(
    'raw',
    keyMaterial,
    { name: 'AES-GCM', length: 256 },
    false,
    ['encrypt', 'decrypt']
  );
};
```

### データの暗号化・復号化フロー

1. **初回セットアップ**
   - Windows Helloで認証
   - WebAuthn経由で鍵ペア生成
   - credentialIdをChrome Storageに保存
   - データ暗号化用のAES鍵を導出

2. **パスワード保存時**
   - Windows Helloで認証
   - 導出したAES鍵でパスワードデータを暗号化
   - 暗号化データをChrome Storageに保存

3. **パスワード使用時**
   - Windows Helloで認証
   - 導出したAES鍵で暗号化データを復号化
   - メモリ上で使用（セッション保持）

## 制約事項

### デバイス固有の鍵

- 鍵はTPMに保存されデバイスに紐付く
- **他のPCとの同期は不可能**
- 各PCで個別にセットアップが必要

**対応策**
- 各デバイスで独立して使用
- 将来的にGPG/passリポジトリ同期機能を実装すれば複数デバイス対応可能

### Windows Hello未設定の場合

ユーザーがWindows Helloを設定していない場合：

```typescript
try {
  const credential = await navigator.credentials.create({...});
} catch (error) {
  if (error.name === 'NotSupportedError') {
    // Windows Hello未対応・未設定
    alert('Windows Helloが設定されていません。Windowsの設定からWindows Helloを有効にしてください。');
    // 設定ページへのリンクを表示
  }
}
```

### 動作環境要件

- **OS**: Windows 10 (version 1809以降) または Windows 11
- **ブラウザ**: Google Chrome 67以降
- **ハードウェア**: 
  - TPM 1.2 または 2.0
  - 生体認証デバイス（オプション、PINでも可）

## セッション管理

認証後のセッション保持方法：

```typescript
interface Session {
  encryptionKey: CryptoKey;
  expiresAt: number;
  credentialId: BufferSource;
}

// セッション保持（メモリ上のみ、30分タイムアウト）
let currentSession: Session | null = null;

const createSession = async (key: CryptoKey, credentialId: BufferSource) => {
  currentSession = {
    encryptionKey: key,
    expiresAt: Date.now() + 30 * 60 * 1000, // 30分
    credentialId
  };
};

const isSessionValid = () => {
  return currentSession && currentSession.expiresAt > Date.now();
};
```

## エラーハンドリング

```typescript
const handleAuthError = (error: Error) => {
  switch (error.name) {
    case 'NotSupportedError':
      return 'Windows Helloが設定されていません';
    case 'NotAllowedError':
      return '認証がキャンセルされました';
    case 'SecurityError':
      return 'セキュリティエラーが発生しました';
    case 'InvalidStateError':
      return '既に登録済みです';
    default:
      return '認証エラーが発生しました';
  }
};
```
