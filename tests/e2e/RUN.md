# E2Eテスト実行ガイド

## 概要

このE2Eテストは、Chrome拡張機能として実際にブラウザにロードして動作を検証します。

## 実行方法

### 1. 通常実行（ヘッドレスモード）
```bash
pnpm test:e2e
```

**注意**: ヘッドレスモードでは拡張機能の一部機能が制限されるため、一部のテストが失敗する可能性があります。

### 2. UI付き実行（推奨）
```bash
pnpm test:e2e:ui
```

実際のブラウザが起動し、テストの実行過程を視覚的に確認できます。

### 3. 手動実行
より確実な検証のため、手動でのテストも推奨します：

1. ビルド
```bash
pnpm build
```

2. Chromeで拡張機能を読み込み
   - `chrome://extensions/` を開く
   - 「デベロッパーモード」を有効化
   - 「パッケージ化されていない拡張機能を読み込む」をクリック
   - `dist/` フォルダを選択

3. 動作確認
   - Popupを開いて初期状態を確認
   - Options ページでパスワード管理を確認
   - 任意のWebページでContent Scriptの動作を確認
   - `Ctrl+Shift+S` でスクリーンショット機能を確認

## 既知の制約

### WebAuthn認証
- 自動テストでは実際のWebAuthn認証（Windows Hello）は実行できません
- 認証機能は単体テストで検証済みです
- E2Eテストでは認証以外の統合動作を確認します

### ヘッドレスモード
- Playwrightのヘッドレスモードでは、拡張機能の一部機能が動作しない場合があります
- より確実なテストには、UI付き実行または手動テストを使用してください

## テスト内容

### 1. 拡張機能のロード
- manifest.jsonの読み込み
- Service Workerの起動
- 必要なファイルの存在確認

### 2. Content Script
- パスワードフィールドの検出
- Shadow DOMの作成
- 複数フォームへの対応

### 3. Popup UI
- Popupの表示
- 初期状態（未認証）の確認
- UIコンポーネントの存在確認

### 4. Options UI
- Options ページの表示
- パスワード管理UIの確認
- 設定項目の確認

## トラブルシューティング

### テストがタイムアウトする
- ビルドが正しく完了しているか確認: `pnpm build`
- `dist/` フォルダが存在し、必要なファイルが揃っているか確認

### 拡張機能がロードされない
- manifest.jsonの構文エラーをチェック
- Service Workerのエラーログを確認

### Content Scriptが動作しない
- Content Scriptが正しくビルドされているか確認
- ページのContent Security Policyが厳しすぎないか確認
