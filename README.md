# bg-ss

Windows専用のコンパクトなテキスト情報管理 & スクリーンショットツール Chrome拡張機能

## 概要

bg-ssは、Windows Hello（生体認証・PIN）を使用した安全なテキスト情報管理と、便利なスクリーンショット機能を提供するChrome拡張機能です。

### 主要機能

- **スクリーンショット**: キーボードショートカット（`Ctrl+Shift+S`）で素早く撮影
- **テキスト情報管理**: Windows HelloによるWebAuthn認証で暗号化されたテキスト情報を安全に保存
- **自動入力**: URLマッチングによる情報の自動入力

### セキュリティ

- WebAuthn PRF拡張による暗号化キーの導出
- AES-256-GCM暗号化
- すべてのデータはローカルストレージに暗号化して保存
- セッション管理（タイムアウト、自動ロック）

## 必要要件

- **OS**: Windows 10 1809以降
- **ブラウザ**: Google Chrome 108以降
- **ハードウェア**: TPM 2.0
- **認証**: Windows Hello（PIN、指紋、顔認証）の設定が必要

## インストール

### 開発版のインストール

1. **依存関係のインストール**
   ```bash
   pnpm install
   ```

2. **ビルド**
   ```bash
   pnpm build
   ```

3. **Chrome拡張機能として読み込み**
   - Chromeで `chrome://extensions/` を開く
   - 「デベロッパーモード」を有効化
   - 「パッケージ化されていない拡張機能を読み込む」をクリック
   - `dist/` フォルダを選択

## 使い方

### 初回設定

1. 拡張機能のPopupを開く
2. 「認証」ボタンをクリック
3. Windows Helloで認証（初回はWebAuthn認証情報を作成）

### テキスト情報の管理

1. 拡張機能のOptionsページを開く（Popupから「設定」リンク）
2. 「新規追加」ボタンで情報を追加
   - **タイトル**: サイト名など（省略可：URLまたは現在時刻が自動設定される）
   - **ユーザー名**: 必須
   - **テキスト情報**: 必須（パスワード等）
   - **URL**: 複数登録可能、改行区切り（省略可）
     - 自動整形: `https://`や末尾の`/`は自動で除去されます
     - 例: `https://example.com/` → `example.com`
   - **追加フィールド**: ユーザー名・テキスト情報以外のフィールド（電話番号、メールアドレスなど）
     - 「+ フィールドを追加」ボタンで追加
     - フィールド名、値、セレクタ（省略可）を入力

**自動検出:**
- フォームで右クリック →「現在のフォームを保存」で全フィールドを自動検出
- 任意のフィールドを自動的に追加フィールドとして保存

**URL管理:**
- 登録外のURLで自動入力を行うと、そのURLを追加するか確認ダイアログが表示されます
- 承認すると、正規化されたURLが自動的に追加されます

### 自動入力

1. 入力フィールドがあるページを開く
2. 入力フィールドで右クリック
3. コンテキストメニューから「bg-ss」→「情報を入力...」を選択
4. Popupで候補を選択
5. 「すべて入力」または個別フィールドを選択
   - すべて入力: ユーザー名、テキスト情報、追加フィールドをまとめて入力
   - 個別入力: 特定のフィールドのみ選択して入力
6. 「✏️ フィールドを編集...」から追加フィールドをその場で編集可能

### スクリーンショット

- `Ctrl+Shift+S`: 現在のタブのスクリーンショットを撮影してダウンロード

## セキュリティ考慮事項

### 暗号化の仕組み

1. WebAuthn認証時にPRF拡張を使用して32バイトの疑似乱数を取得
2. HKDF-SHA256でAES-256-GCM用の暗号化キーを導出
3. パスワードをJSON形式でシリアライズして暗号化
4. 暗号化データをChrome Storageに保存

### セッション管理

- デフォルトのセッションタイムアウト: 30分
- 自動ロック機能
- セッション期限切れ後は再認証が必要

### 注意事項

- 保存したデータはデバイスに紐づいており、別のPCでは使用できません
- Windows Helloの認証情報が失われると、保存したデータは復号できなくなります
- 重要な情報は別途バックアップを取ることを推奨します

## 制約事項

- **Windows専用**: macOS、Linuxでは動作しません
- **Chrome専用**: Firefox、Edgeなど他のブラウザでは動作しません（Chromiumベースなら動作する可能性あり）
- **デバイス依存**: 認証情報はデバイスに紐づいており、複数デバイス間での同期は未対応
